# Captured offline analysis cases

Run `python -m examples.offline_case` from the installed checkout. The real analysis coordinator receives explicitly authored synthetic provider responses through an injected adapter; no provider or GitHub request occurs.

[Complete captured output](result.json) contains two cases:

| Case | Response saved exactly | Later project schema |
| --- | --- | --- |
| Structured fixture | Yes | Pass |
| Raw prose fixture | Yes | Fail with JSONDecodeError |

Each case includes the full synthetic source, exact prompt messages, saved raw response, schema result and compatibility classification. Neither performs human approval or publication.

The translator allows raw prose as well as JSON. The valid project JSON was deliberately authored for this example, not generated by a live model. “Supported” records successful text response handling; it is not a claim that the project schema or proposed work is correct.
